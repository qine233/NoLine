# NoLine  ai-1.0

> 一个克制、无描边的 Typecho 主题。

NoLine 主张「无描边卡片」与「设计令牌驱动」的视觉语言。它不靠重描边和强阴影划分层次，
而是用留白、圆角与一套统一的颜色令牌，让内容自己说话。

---

## 特性

### 设计系统
- **设计令牌驱动**：所有颜色集中在 `:root`，浅色与深色各一套，强调色可在后台配置，换肤不再翻十几个文件。
- **无描边卡片语言**：首页信息流与文章页共用一套卡片规范，视觉统一。
- **深浅色双模式**：支持系统偏好跟随与手动切换，`localStorage` 记忆，初始化脚本前置，无闪烁。
- **无障碍与动效**：完整 `aria-*` 标注、`sr-only` 辅助文本，支持 `prefers-reduced-motion`。

### 内容排版
- **动态 / 说说卡片**：为短内容单独设计的紧凑排版，正文 15px、行高 1.85，标题压平，代码块不带红绿灯，长文自动折叠出「全文」按钮。
- **完整文章排版**：二级标题下划线、引用块、表格、脚注、图片圆角、有序 / 无序嵌套列表一应俱全。
- **代码块增强**：highlight.js 语法高亮、红绿灯圆点钉住横向滚动、复制按钮不随内容滚动、无语言代码块浅色兜底。
- **评论区**：表单 + 嵌套回复 + 待审状态 + 评论内独立代码块样式。

### 站点组件
- **顶栏**：主导航、分类下拉（多级缩进）、搜索、社交入口、阅读进度百分比、深浅色切换、移动端下拉菜单。
- **侧边栏**：十月历、那年今日、近期评论、分类、标签、站点信息。
- **分页与导航**：分页器、上下篇导航、文章底部标签。

### 工程细节
- 资源版本化（`?v=x.y.z`）。
- 顶栏 `backdrop-filter` 与 `position: fixed` 冲突已处理：进度条与遮罩移出 `.topbar`。
- 主题初始化脚本前置，消除深色模式闪烁。
